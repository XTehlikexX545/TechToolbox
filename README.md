# TechToolbox

A collection of practical web-based developer tools built with HTML, CSS, and JavaScript.

HTML, CSS ve JavaScript kullanılarak geliştirilmiş, pratik web tabanlı geliştirici araçlarından oluşan bir koleksiyon.

---

## 🇬🇧 English

### Overview

TechToolbox is a lightweight web application designed to bring useful developer utilities together in one place. The project focuses on making everyday development tasks accessible through a simple browser-based interface.

### Technologies

- **HTML5** for page structure
- **CSS3** for styling and layout
- **JavaScript** for interactive functionality

### Project Structure

```text
TechToolbox/
├── index.html
├── style.css
├── app.js
└── README.md
```

### Getting Started

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Explore the available tools and functionality.

No build tools or package installation are required for the current project structure.

### Development

- `index.html` defines the application interface.
- `style.css` contains the visual styling.
- `app.js` handles application logic and interactions.

### Project Status

TechToolbox is an ongoing personal development project. Features and improvements may be added as development continues.
